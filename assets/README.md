# Profile assets

The animated header and static alternative are generated by `scripts/build_header.py`
using Pillow. The GIF repeats every 10.8 seconds, without flashing. The profile
uses the static PNG when the viewer requests reduced motion.

Technology icons are from [Devicon](https://github.com/devicons/devicon), downloaded
on 2 November 2026. Their MIT license is included in `icons/LICENSE`.
Brand names and logos belong to their respective owners and identify the tools used;
they do not imply endorsement.
